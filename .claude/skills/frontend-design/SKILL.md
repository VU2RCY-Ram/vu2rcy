This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

The user provides frontend requirements: a component, page, application, or interface to build. They may include context about the purpose, audience, or technical constraints.

## Design Thinking

Before coding, understand the context and commit to a BOLD aesthetic direction:
- **Purpose**: Interfaces inspired by a devoted ham radio operator's journey—communication, exploration, and signal discovery across the globe.
- **Tone**: Retro-technical meets modern precision — analog dials, frequency grids, signal noise, satellite paths, and RF-inspired visuals blended with clean, cutting-edge UI.
- **Constraints**: Technical requirements (framework, performance, accessibility).
- **Differentiation**: Feels like operating a modernized radio console — frequency scanning, waveform motion, grid overlays, and global connectivity themes. The identity should reflect evolution from VU3MGR to VU2RCY and decades of experimentation since 1988.

**CRITICAL**: Choose a clear conceptual direction and execute it with precision. The design should feel like a fusion of legacy radio hardware and futuristic communication systems.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:
- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point-of-view
- Meticulously refined in every detail

## Frontend Aesthetics Guidelines

Focus on:
- **Typography**: Use technical, signal-inspired, or instrumentation-style fonts for headings (e.g., mono, stencil, or display fonts reminiscent of radio equipment), paired with a clean readable body font.
- **Color & Theme**: Deep blacks, phosphor greens, amber tones, signal blues, and RF spectrum accents. Use contrast like glowing indicators, LED-style highlights, and subtle noise textures.
- **Motion**: Simulate signal scanning, waveform pulsing, frequency tuning, and satellite tracking. Smooth but purposeful motion — like equipment feedback, not decorative fluff.
- **Spatial Composition**: Dashboard-like layouts, modular panels, grid overlays, spectrum bars, and asymmetric console-inspired sections.
- **Backgrounds & Visual Details**: Oscilloscope lines, frequency waves, map overlays, satellite arcs, static noise textures, and layered UI resembling radio interfaces.

NEVER use generic AI-generated aesthetics like overused font families (Inter, Roboto, Arial, system fonts), cliched color schemes, predictable layouts, or cookie-cutter components.

Interpret creatively and make unexpected choices that feel genuinely designed for this domain — a lifelong ham radio operator embracing evolving technology and global communication.

**IMPORTANT**: Match implementation complexity to the aesthetic vision. The interface should feel like a living system — reactive, precise, and engineered.

Remember: The design should capture curiosity, experimentation, and the spirit of global connection through radio.
